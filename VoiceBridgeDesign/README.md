# Heard

Design-only Next.js mobile UI for accessible conversation and sharing.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the **landing** page.

## Pages

- **/** — landing: soft-orb aesthetic, story scroll, Launch app
- **Live** — conversation demo: partner transcript, record → confirm / word fix
- **Share** — suggestions, record → confirm → system share
- **My Words** — understood-first-time progress, personal vocabulary, still learning
